# Administrator documentation

Use this guide to manage student-facing copy safely. Draft changes stay private until an administrator publishes them.

<h2 id="student-banners">Student banners</h2>

Student banners contain the heading and supporting text shown at the top of Beranda, Materi, Kuis, and Tryout.

### Update banner copy

1. Open **Admin → Student banners**.
2. Find the section that matches the student page you want to update. All four editors are displayed on the same page.
3. Keep the heading short. Use the supporting text to explain the next useful action or piece of context.
4. Select **Preview** to review the current form values. The preview uses sample student data for Beranda placeholders.
5. Select **Save draft** to keep the edits private.
6. Select **Publish** after saving the draft to make that saved copy live for students.

Saving a draft does not change any student page. Publishing updates the four student routes and the new copy appears on the next student page load. The status badge on the editor shows whether unpublished draft changes remain.

| Banner | Student route |
| --- | --- |
| Beranda | `/dashboard` |
| Materi | `/courses` |
| Kuis | `/quiz` |
| Tryout | `/tryout` |

<h2 id="placeholders">Placeholders</h2>

Beranda can personalize copy for each student with these placeholders:

```text
{firstName}
{target}
```

- `{firstName}` is replaced with the student&apos;s first name.
- `{target}` is replaced with the student&apos;s study target.

For example:

```text
Halo, {firstName}.
Semangat mengejar {target} ya!
```

<DocCallout tone="warning">
  Materi, Kuis, and Tryout use plain text only. If `{firstName}` or `{target}` is entered in one of those banners, saving is blocked until the placeholder is removed.
</DocCallout>

<h2 id="preview-and-publishing">Preview and publishing</h2>

The editor has three separate controls:

- **Preview** renders the unsaved values currently in the form. It does not write to the database or change student pages.
- **Save draft** stores the values privately so another administrator can continue the work later.
- **Publish** promotes the saved draft to the student-facing copy and clears the unpublished draft status. Save again first if you have made additional edits since the last draft save.

If another administrator saves the same banner while your page is open, the editor asks you to refresh before saving or publishing. This prevents an older tab from silently replacing newer work.

<h2 id="publishing-checklist">Publishing checklist</h2>

- The heading names the page or next action clearly.
- The supporting text adds context instead of repeating the heading.
- Placeholders appear only in Beranda.
- Preview shows the intended result.
- The success confirmation appears after saving or publishing.
