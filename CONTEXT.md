# Glosarium Vecalss

Dokumen ini mencatat arti istilah produk agar copy di seluruh pengalaman
Vecalss tetap konsisten.

| Istilah | Arti dan penggunaan |
| --- | --- |
| Voyager | Nama brand untuk siswa. Gunakan terutama pada onboarding, sapaan, dan momen apresiasi. Untuk instruksi sehari-hari, sapa siswa dengan “kamu”. |
| Kapten | Nama brand untuk tutor dan penulis konten. Jangan menggantinya dengan “mentor” atau “guru” di label produk tanpa alasan konteks. |
| Program | Gunakan untuk program belajar yang memang bernama atau dijelaskan sebagai program. Jangan pakai sebagai sinonim untuk kelas, Materi, atau Kuis. |
| Kelas | Kelompok belajar siswa. Jangan gunakan sebagai nama lain untuk katalog Materi atau kumpulan unit. |
| Materi | Konten belajar yang dibaca atau ditonton siswa. Gunakan juga untuk nama area belajar yang berisi materi. |
| Mata pelajaran | Kelompok bidang pelajaran pada katalog Bank Soal. Bedakan dari subtes; periksa konteks halaman sebelum memilih istilah. |
| Impor | Proses menambahkan atau memperbarui banyak akun dari file CSV. Gunakan “impor” pada antarmuka; jangan tampilkan “import”. |
| Draf | Data impor yang masih ditinjau dan belum mengubah akun. Gunakan “draf” untuk statusnya. |
| Pratinjau | Ringkasan isi file dan perubahan akun sebelum impor dimulai. Gunakan “pratinjau”, bukan “preview”. |
| Informasi akses | Kata sandi sementara atau tautan undangan yang diberikan kepada penerima. Hindari istilah internal “handoff”. |
| Subtes | Bagian mata uji seperti PU atau PBM. Gunakan untuk mengelompokkan Materi atau soal berdasarkan bagian ujian; jangan samakan dengan mata pelajaran. |
| Unit | Satu bagian belajar berurutan di dalam Materi. Pertahankan label “Unit 1” yang sudah dipakai produk. |
| Kuis | Kegiatan latihan mandiri dengan soal dan hasil. Gunakan “Kuis” untuk nama fiturnya; “latihan” boleh digunakan untuk menyebut kegiatan berlatih secara umum. |
| Bank Soal | Kumpulan soal yang dapat dipilih untuk menyusun Kuis atau Tryout. Jangan gunakan “Question Bank” pada antarmuka. |
| Paket Soal | Kumpulan soal yang disiapkan untuk digunakan dalam Tryout. Bedakan dari Bank Soal, yang menjadi sumber pemilihan soal. |
| Tryout | Simulasi ujian dengan sesi, batas waktu, pengumpulan jawaban, dan hasil yang dapat dirilis. Pertahankan ejaan “Tryout”. |
| Poin tetap | Nama metode penilaian Tryout yang menampilkan poin yang ditetapkan per soal. Gunakan kapitalisasi sesuai label “Poin tetap” di editor. |
| Media | File gambar atau PDF yang digunakan di konten. Gunakan “pustaka media” untuk area pengelolaannya, “unggah” untuk menambahkan file, “unduh” untuk menyimpan file, dan “pratinjau” untuk melihatnya. |
| Sesi Tryout | Waktu dan akses yang disediakan untuk mengerjakan suatu Tryout. Bedakan dari pengerjaan siswa. |
| Pengerjaan | Aktivitas atau riwayat ketika siswa mengerjakan Kuis atau Tryout. Gunakan “percobaan” jika yang dimaksud adalah jatah mengulang. |
| Tugas | Pekerjaan yang memang ditugaskan dan dikumpulkan. Jangan gunakan untuk menyebut Kuis atau Tryout. |
| Jawaban | Respons siswa terhadap soal. “Kunci jawaban” adalah jawaban benar; “pembahasan” adalah penjelasan untuk membantu siswa memahami soal. |
| Kumpulkan | Tindakan final mengirim jawaban atau pekerjaan. Gunakan “Simpan jawaban” untuk penyimpanan yang masih dapat dilanjutkan; jangan menyamakan keduanya. |
| Skor | Angka hasil Kuis atau Tryout. Gunakan “nilai” untuk nilai akademik ketika memang itu yang ditampilkan. |
| Progres | Perkembangan belajar. Gunakan ejaan “progres”, bukan “progress”. |
| Batas waktu | Waktu akhir untuk mengerjakan atau mengumpulkan. Untuk ujian yang sedang berlangsung, gunakan “waktu tersisa”. |
| Email, kata sandi, dan tautan undangan | Gunakan “Email”, “kata sandi”, dan “tautan undangan” pada antarmuka. Gunakan “Masuk” untuk tindakan membuka akun; “login” hanya dipakai saat membahas istilah teknis. |
