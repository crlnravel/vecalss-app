## Description:

Rewrite, edit, or review Indonesian text so it sounds natural, human, and context-appropriate.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ramaaditya49](https://clawhub.ai/user/ramaaditya49)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, editors, marketers, and developers use this skill to make Indonesian text more natural while preserving meaning, facts, intent, and voice. It supports formal, professional, casual, sales, academic, and technical registers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: File-edit requests may directly modify the target text.

Mitigation: Review important writing after edits before relying on or publishing it.

Risk: The skill is not a fact checker and should not create new proof, citations, numbers, or claims.

Mitigation: Verify factual claims separately and use the skill only to preserve or clarify supplied content.
