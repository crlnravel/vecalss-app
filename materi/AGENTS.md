# Learning PDF conversions

When rebuilding or restyling learning PDFs in this directory, follow
[`_framework/README.md`](_framework/README.md) and
[`../docs/materi-pdf-workflow-guide.md`](../docs/materi-pdf-workflow-guide.md).
Retypeset the complete original wording verbatim into editable lesson JSON, then
generate a new document with PTN Pro branding, the mascot header logo, justified
body text, and green top and bottom bands. Double-check source-to-output text
fidelity and layout. Source PDF pages are reference material, never backgrounds
or overlays. Change wording, examples, punctuation, questions, or answers only
when the user explicitly requests content editing.

The repository's `AGENTS.md`, `DESIGN.md`, copywriting rules, resource guard,
and model permission policy continue to apply.
