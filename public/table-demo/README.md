# Table demo assets

These assets are limited to `/admin/table-demo`, an explicitly simulated table.

- `inter.ttf`: Google Fonts Inter variable font, licensed under the SIL Open Font License in `OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/inter.
- `avatar-0.jpg` through `avatar-5.jpg`: illustrative sample portraits from https://randomuser.me/api/portraits/ (women/44, men/32, men/33, women/47, women/49, men/11). Names and transactions are fictional and do not describe the pictured people.
- Card marks are independently drawn in the demo's CSS for the reference layout.

The visual reference is https://github.com/keenthemes/reui/blob/main/public/screenshots/blocks/data-grid/virtualization-light.png. The table implementation is independently authored; it contains no licensed ReUI block source.
